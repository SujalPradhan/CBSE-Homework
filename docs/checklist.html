Does it still teach if a student uses AI?

Each task was attacked by an AI agent acting as a student with a coding agent and a browser, on 13 Oct 2026. It could not see the grading code. Below is what happened, what we fixed, and what we could not fix.

The short answer

What the server stops: copying a classmate's numbers (exact or almost exact), using someone else's roll number, careless made-up numbers, and numbers that break the textbook rule or basic physics.

What it does not stop: an AI that knows the physics can invent realistic numbers, first try, for every task.

So the design puts the real check in class. A ✓ on the teacher's list means "the numbers look real". It does not mean "done". The 2-minute question on a fresh case, plus the family member's sentence in the notebook, is what shows learning. This matches the presence pattern in The Exam Is a Hypothesis.

The checklist, extended for schools

The first six tests and the seventh are from Anand S's TDS ideation session. The last five are added for Grades 6–8.

Fixed after the red-team

  • A PIN per roll number, so no one can lock a wrong prediction or use up tries for a classmate. After 10 wrong PINs the roll locks and the teacher can reset it.
  • Near-copies (all numbers within 2%) are flagged, not only exact copies.
  • Rolls that finish within 3 minutes of predicting are flagged.
  • Typing mistakes (out-of-range numbers) no longer use up a try.
  • The hand-area task now checks the textbook's part-square rule.
  • The bottle task requires the bottle on a stool, so the result matches the lesson.
  • Class results show only one summary number per student, not everyone's raw measurements.
  • Class creation is rate-limited, which makes it harder to use the server as a free answer checker.

Known limits

  • An AI can produce realistic numbers for every task. The server cannot tell these from real measurements.
  • A script that waits a few minutes and varies its numbers by 3% or more is not flagged.
  • A student could claim a classmate's unused roll number first. The teacher can reset it.
  • The tolerances can still be mapped with enough effort (the red-team found the pendulum window in 13 submissions before the class limit was added).
  • Nothing has been tried with real students yet. The first classroom trial is the real test.
